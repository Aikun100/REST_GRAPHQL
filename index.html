Local Running Instructions

Open your terminal in c:\laragon\www\api-showcase and run:

# 1. Install all dependencies
npm run install:all

# 2. Start the GraphQL Server (runs on port 4000)
npm run start:graphql

# 3. Start the REST Server (runs on port 5000 in a new window)
npm run start:rest

Vercel Deployment

  1. Install the Vercel CLI (npm install -g vercel) or push the codebase to GitHub.
  2. To deploy the GraphQL Program, run vercel inside the graphql-program folder.
  3. To deploy the REST Program, run vercel inside the rest-program folder.
  4. Vercel will detect vercel.json, build the backend api/index.js files as Vercel Serverless Functions, and host the static frontends on the root domain!
